## Overview
Built for people who fly DJI drones professionally or as a serious hobby, DJI Pilot for Windows combines a live flight display, mission planning tools, and payload camera controls into one interface. Rather than switching between separate flight and camera apps, pilots get telemetry, a map-based route planner, and video feed review in the same window. It's meant to make repeat flights — inspections, surveys, mapping runs — faster to set up and easier to repeat consistently.
